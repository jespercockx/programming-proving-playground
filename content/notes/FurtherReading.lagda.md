-  The official Agda documentation. [^1]
-  The Agda standard library. [^2]
-  Philip Wadler, Wen Kokke, and Jeremy Siek: *Programming Language
  Foundations in Agda*[^3] (online
  book). This book focuses mainly on using Agda to explain core ideas
  from programming languages research, but it is also generally an
  excellent first introduction to Agda.
-  Aaron Stump: *Verified Functional Programming in Agda* [^4]
  (physical book, first two chapters are freely available). This book
  also starts from the basics and builds towards using Agda as a
  language to implement and verify functional programs.
-  Ulf Norell and James Chapman: *Dependently Typed
  Programming in Agda* [^5]
  (tutorial in `pdf` format).
-  Ana Bove and Peter Dybjer: *Dependent Types at Work* [^6]
  (tutorial in `pdf` format).
-  Andreas Abel: *An Introduction to Dependent Types and Agda* [^7] (lecture notes).
-  Andreas Abel: *Agda Equality* [^8] (lecture
  notes).
